# FitZone Gym Website

A simple gym membership website built with HTML, CSS and JavaScript. Visitors can look at the membership plans and register for one using the form.

## Features

- Navbar with smooth-scroll links
- Hero section with a background image
- "Why FitZone?" section
- Three membership plans: Basic, Standard and Premium
- Registration form (name, age and plan) with a success message

## Files

| File | What it does |
| --- | --- |
| `gym.html` | Page structure and the form script |
| `Gymcss.css` | All the styling |
| `gym-bg.jpg` | Hero background image (add your own) |

## How to Run

1. Keep `gym.html`, `Gymcss.css` and `gym-bg.jpg` in the same folder.
2. Open `gym.html` in any web browser.

No installation needed.

## Background Image

Add any gym photo to the project folder and name it `gym-bg.jpg`. To use a different file name, change it in the `.hero` rule in `Gymcss.css`.
